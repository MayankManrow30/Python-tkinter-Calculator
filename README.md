# Calculator App

A simple calculator application built with Python and Tkinter.

## Features

- ➕ **Addition** - Add two or more numbers
- ➖ **Subtraction** - Subtract numbers
- ✖️ **Multiplication** - Multiply numbers
- ➗ **Division** - Divide numbers with error handling
- 🔢 **Decimal Support** - Work with floating-point numbers
- ⌫ **Clear Function** - Reset calculator
- 🎨 **User-Friendly Interface** - Clean and intuitive design
- ⚡ **Fast and Responsive** - Instant calculations
- 🖥️ **Cross-Platform** - Works on Windows, Mac, and Linux



## 🔧 Requirements

- Python 3 or higher
- Tkinter (usually comes pre-installed with Python)
